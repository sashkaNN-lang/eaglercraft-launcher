📖 О ПРОЕКТЕ

Eaglercraft Launcher запускает версии Eaglercraft локально в один клик. Он стартует локальный HTTP-сервер и отдаёт игру.

Три интерфейса:
- CLI (main.py) — простое текстовое меню
- GUI (mainGUI.py) — тёмное окно, игра открывается в браузере
- GUI Native (mainGUIweb.py) — то же окно, игра открывается в отдельном окне через pywebview

Все поддерживают английский и русский.

────────────────────────────────────────

✨ ВОЗМОЖНОСТИ

- Версии: 1.3 beta, 1.5.2, 1.7.3 beta, Indev, Scratch, 1.8.8, 1.12.2, 26.2
- Загрузчики WASM / JS для 1.8.8 и 1.12.2
- Интерфейс на английском и русском
- Автооткрытие браузера (CLI / GUI) или отдельного окна (GUI Native)
- Без зависимостей для CLI и GUI — только стандартная библиотека Python
- pywebview требуется для GUI Native (устанавливается через install.cmd)

────────────────────────────────────────

📋 ТРЕБОВАНИЯ

- Python 3.10 или новее
- Windows 10 / 11
- Любой современный браузер
- ~250 МБ свободного места для игровых файлов

Для GUI Native (mainGUIweb.py):
- pywebview (устанавливается через install.cmd)
- Microsoft Edge WebView2 (обычно уже установлен на Windows 10/11)

────────────────────────────────────────

🎮 ЗАПУСК

Способ 1 — двойной клик по start.cmd, выбери 1, 2 или 3.

Способ 2 — запусти вручную:

    python main.py          (CLI)
    python mainGUI.py       (GUI — открывает в браузере)
    python mainGUIweb.py    (GUI Native — открывает в отдельном окне)

Дальше выбери язык, версию, загрузчик (если нужно) — игра откроется сама.

Остановка: закрой окно или нажми Enter.
