🎮 Eaglercraft Launcher

Простой локальный лаунчер для Eaglercraft — запускай любую версию прямо в браузере.

📖 О ПРОЕКТЕ

Eaglercraft Launcher запускает версии Eaglercraft локально в один клик. Он стартует локальный HTTP-сервер, открывает браузер и отдаёт игру.

Два интерфейса:
- CLI (main.py)
- GUI (mainGUI.py)

Оба поддерживают английский и русский.

────────────────────────────────────────

🎮 ЗАПУСК

Способ 1 — двойной клик по start.cmd, выбери 1 или 2.

Способ 2 — запусти вручную:

    python main.py       (CLI)
    python mainGUI.py    (GUI)

Дальше выбери язык, версию, загрузчик (если нужно) — браузер откроется сам.

Остановка: закрой окно или нажми Enter.
