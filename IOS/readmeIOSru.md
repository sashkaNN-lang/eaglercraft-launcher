# Eaglercraft Launcher — iOS

Версия лаунчера для iPhone и iPad через приложение **a-Shell mini**.

Основной проект (Windows).

## 📖 О ПРОЕКТЕ

iOS-версия Eaglercraft Launcher работает через **a-Shell mini** — терминал с Python для iPhone и iPad.

Поскольку в iOS нет `.cmd` и `tkinter`, эта версия:
- Использует **Shortcuts** (команды) вместо `start.cmd`
- Работает **только через CLI** (текстовое меню)
- Открывает игру в **Safari**

## 🚀 БЫСТРЫЙ СТАРТ

### Шаг 1: Установи a-Shell mini

Скачай **a-Shell mini** из App Store. Это бесплатно.

### Шаг 2: Установи лаунчер

Открой ссылку на шорткат установки:

**https://www.icloud.com/shortcuts/7b6d0e7233e044a4a9a6353c24aeadaa**

Нажми **«Добавить команду»** → запусти её.

Шорткат:
- Скачает `.zip` последнего релиза с GitHub
- Распакует в `~/Documents/eaglercraft-launcher`
- Подготовит всё к запуску

### Шаг 3: Запусти лаунчер

Открой ссылку на шорткат запуска:

**https://www.icloud.com/shortcuts/3309b90b659f445ea9430e579ae33e98**

Нажми **«Добавить команду»** → запусти её.

Шорткат:
- Откроет a-Shell mini
- Запустит `python main.py`
- Ты выберешь язык, версию, загрузчик
- Safari откроется автоматически с игрой

### Шаг 4: Играй

Игра открывается в **Safari**. Выбирай версию, играй.
